Indexes start at 0.An array of 5 items has indexes 0, 1, 2, 3 and 4.

    
Size is fixed.After you write marks[5] in the declaration, the array can’t grow.

    
C doesn’t check bounds.Going past the last index compiles fine but breaks your program.
